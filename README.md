# Paytm Money — Security & Governance Posture Dashboard

A modern, high-performance executive and operational security posture dashboard built with React, Vite, and Tailwind CSS.

## 🚀 Key Features

- **Executive Overview**: Consolidated risk posture scores, radial posture meter, findings distribution waterfall, and enterprise risk heat map.
- **AWS Cloud Security (`/aws`)**: Complete assessment across 15 production AWS accounts, 14 service areas, and 75 security findings with systemic gap analysis.
- **AWS Accounts Command Center (`/aws-accounts`)**: 15-account interactive selector deck, per-account drilldowns, and real-time finding filters.
- **Google Workspace (`/gws`)**: IAM maturity, positive controls, and privilege misuse audit.
- **Identity Governance & Administration (`/iga`)**: 44 IGA controls across 9 governance domains, PAM maturity, SoD conflict matrix, and certification cadences.
- **Compliance & Frameworks (`/control-status`, `/framework-mapping`)**: Full cross-mappings against SEBI CSCRF, RBI Master Direction, NIST CSF 2.0, and ISO/IEC 27001.
- **Remediation & Action Plan (`/priority-actions`, `/action-plan`, `/roadmap`)**: 0–180 day priority actions, management action plan with owner tracking, and a 12-month security transformation roadmap.
- **Audit & Evidence (`/evidence`, `/source-reports`)**: Audit traceability, lifecycle stages, and source reports.

## 🛠️ Tech Stack

- **Framework**: React 18 + Vite
- **Styling**: Tailwind CSS with Paytm Design System (`#002970`, `#00baf2`, `#f5f9fe`)
- **Routing**: React Router DOM v6
- **Typography**: Inter
